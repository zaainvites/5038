GITHUB PAGES SETUP

Upload these 3 files to your repository root:
1. index.html
2. styles.css
3. script.js

Create an assets folder and upload:
- cover.png
- music.mp3
- opening.mp4 (optional)
- video-01.mp4
- video-02.mp4
- video-03.mp4
- photo-01.jpg
- photo-02.jpg
- photo-03.jpg
- photo-04.jpg

Then GitHub:
Settings > Pages > Deploy from branch > main > /(root) > Save

The cover.png included in this ZIP is the invitation image supplied by the client.
